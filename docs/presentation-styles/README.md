# Arkive 暗色展示 PPT 风格样张

2026-10-17。本轮用于选择视觉方向，包含四套方案，每套一页封面、一页内容页，共 8 页。标题和正文是可编辑的 PowerPoint 文本；主视觉为独立位图。正式路演的文案、团队信息和 Demo 顺序待风格选定后展开。

## 查看方式

- `index.html`：可离线打开的预览页，支持放大、左右方向键翻页、选择风格。选择仅保存在本地浏览器中，不会自动发送到聊天。
- `style-overview.png`：四套封面的对比总览。
- `all-slides.png`：八页完整缩略图。
- `Arkive-dark-style-options.pptx`：可编辑的 16:9 样张。
- `previews/`：逐页 1920 × 1080 预览。

## 四个方向

| 方向 | 页码 | 视觉特点 | 内容页排版 | 适合的表达 |
| --- | --- | --- | --- | --- |
| A · 曜石极简 | 1–2 | 黑银配色、金属层叠、大标题与留白 | 左侧流程、右侧产品界面 | 产品发布会、强调简洁和可靠 |
| B · 午夜蓝科技 | 3–4 | 深蓝底色、蓝色玻璃光带、中文主标题 | 顶部结论、左侧界面、右侧技术说明 | 技术路演、讲解 Agent 与业务服务 |
| C · 石墨绿工程 | 5–6 | 石墨绿、低饱和金属线圈、等宽字与序号 | 大标题、四行文件生命周期说明 | 工程实现、清楚讲解处理规则 |
| D · 暗紫渐变 | 7–8 | 深紫底色、玻璃拱形、淡紫与玫瑰反光 | 居中产品界面、两侧短说明 | 创意产品展示、强调视觉氛围 |

建议先看 A 与 B。A 更接近简洁的产品发布会；B 的正文分区适合技术解释。也可以采用 A 的封面风格与 B 的内容布局，统一为一种配色。
