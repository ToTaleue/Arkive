## 参考来源与待补充材料

Ghostscript 当前二进制经 Clop v3.5.0 固定提交 21a71a0707c3c92907d569b2fa4ac7ac726ff713 提取；这是二进制来源，不代表 Arkive 由 Clop 整体复刻。工具清单中 Ghostscript 和 pngquant 的分发材料存在待核验标记，正式对外分发前应补齐相应来源、构建与声明材料。

项目规划参考 Clop 的工具调用与处理思路，并复用 Mole 的随包运行与分类能力。自主设计范围见主说明书第三节。

## 模型 API 数据集与展示素材

展示模型已选定为 Deepseek V4.1 Flash。API 服务商与接口准确模型 ID 随演示配置记录，真实模型端到端行为仍需联测。项目通过 Pi SDK 提供可配置模型接入，不随包发布模型权重，不申报自研或微调基础模型。实测时补充公开模型标识、服务商页面、接口用途与数据发送范围；不公开密钥。

没有申报训练数据集。已有回归使用程序生成的图片与文档、隔离测试目录和本地 HTTP 模型响应夹具；这不是模型训练数据。外部 DJI 或其他演示样本如使用，须由队伍说明来源与授权。

当前简约展示稿的文件与流程图为原生图形，界面截图来自项目已有测试与前端渲染预览；没有把生成意象图片作为真实执行证据。文稿和展示材料由 AI 工具辅助编辑，功能事实以源码和报告为准。
